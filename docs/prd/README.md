# PRDs

New PRDs live in GitHub Issues (see `docs/agents/issue-tracker.md`). This folder holds only PRDs for work that has not shipped yet.

None is open: on 2026-10-26 every PRD here was checked against its issues and shipped code, found shipped, and moved to [`archive/2026/`](archive/2026/) (#2251). A PRD's own `**Status:**` line is frozen at authoring time — it is not a shipped/unbuilt signal.
